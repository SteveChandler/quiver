App Vision
A community-driven surf app (like AllTrails but for surfers) where users can:

Plan surf sessions

Review beaches and conditions

Upload photos/videos

Log personal boards

View real-time surf forecasts

Build social connections and surf crews

Tech Stack
Frontend: Next.js (App Router), Tailwind CSS, Shadcn UI

Backend/Database: Supabase (PostgreSQL, Auth, API)

Media Storage: Firebase (for photos/videos)

Current Features (Implemented)
✅ Real-time Forecasts: Integration with forecast APIs
✅ Responsive Design: Mobile-first with tablet support

Folder Structure
A full surfing-app/ directory structure organized with:
- app/ for Next.js pages and API routes
- components/ for reusable UI elements
- lib/ for Supabase and Firebase setup
- types/ for TypeScript definitions
- hooks/ for custom React hooks
- context/ for state management
