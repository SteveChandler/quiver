## What This Migration Does

Adds 4 new columns to `sessions` table:
- `wave_height_ft` - Wave height in feet (decimal)
- `wind_speed_mph` - Wind speed in mph (integer)
- `wind_direction` - Wind direction (text)
- `forecast_accuracy` - Forecast accuracy feedback (text: accurate/somewhat/inaccurate)

**Zero breaking changes.** All columns are nullable.

## Common Questions

**Q: Will this break existing sessions?**
A: No. All columns are nullable. Old sessions work fine.

**Q: Do I need to update RLS policies?**
A: No. New columns inherit existing policies automatically.

**Q: What if I don't update the UI code yet?**
A: Fine! New columns will just have NULL values until UI is updated.

A: Yes! Just run `npx supabase db reset` - it's safe.
