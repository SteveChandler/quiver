## 📊 Database Schema

### **profiles** table (modified)
```sql
referral_code TEXT UNIQUE  -- User's personal code to share
```

### **referrals** table (new)
```sql
id              UUID PRIMARY KEY
referrer_id     UUID NOT NULL → profiles.id  -- Who shared
referee_id      UUID NOT NULL → profiles.id  -- Who used (UNIQUE)
referral_code   TEXT NOT NULL                -- Code entered
status          TEXT CHECK (pending/completed/expired)
completed_at    TIMESTAMPTZ
created_at      TIMESTAMPTZ NOT NULL
updated_at      TIMESTAMPTZ NOT NULL
```

## 🔧 Common Queries

### Look up referrer by code
```sql
SELECT id, display_name, referral_code
FROM profiles
WHERE LOWER(referral_code) = LOWER('ABC123');
```
**Index used**: `idx_profiles_referral_code_lower`

### Create referral record (during onboarding)
```sql
INSERT INTO referrals (
    referrer_id,
    referee_id,
    referral_code,
    status,
    completed_at
) VALUES (
    '...referrer-uuid...',
    '...referee-uuid...',
    'ABC123',
    'completed',
    NOW()
);
```

### Check if user was already referred
```sql
SELECT EXISTS (
    SELECT 1 FROM referrals
    WHERE referee_id = '...user-uuid...'
);
```
**Index used**: `idx_referrals_referee_id`

### Get user's referral stats
```sql
SELECT * FROM get_user_referral_stats('...user-uuid...');
-- Returns: total_referrals, completed_referrals, pending_referrals, expired_referrals, referral_code
```

### Top referrers leaderboard
```sql
SELECT
    p.display_name,
    COUNT(*) FILTER (WHERE r.status = 'completed') AS completed_referrals
FROM profiles p
JOIN referrals r ON r.referrer_id = p.id
GROUP BY p.id, p.display_name
ORDER BY completed_referrals DESC
LIMIT 10;
```
**Index used**: `idx_referrals_referrer_status`

## 🔐 RLS Policies

| Policy | Who | Can Do | Condition |
|--------|-----|--------|-----------|
| View as referrer | Authenticated | SELECT | auth.uid() = referrer_id |
| View as referee | Authenticated | SELECT | auth.uid() = referee_id |
| Create referral | Authenticated | INSERT | auth.uid() = referee_id |
| Update referral | Authenticated | UPDATE | auth.uid() = referee_id |

**⚠️ Important**: No DELETE policy - referrals are immutable!

## 🛡️ Constraints

| Constraint | Rule | Error Message |
|------------|------|---------------|
| `referrals_no_self_referral` | referrer_id ≠ referee_id | User cannot refer themselves |
| `referrals_unique_referee` | UNIQUE(referee_id) | User already referred |
| `referrals_completed_at_when_completed` | status = 'completed' → completed_at NOT NULL | Completion timestamp required |

## 🐛 Common Issues & Solutions

### Issue: "User already referred"
**Cause**: Unique constraint on `referee_id`
**Solution**: Check if user exists in `referrals` table before inserting

```sql
SELECT EXISTS (
    SELECT 1 FROM referrals WHERE referee_id = '...'
) AS already_referred;
```

### Issue: Invalid referral code
**Cause**: Code doesn't exist or typo
**Solution**: Use case-insensitive lookup with `.ilike()` in TypeScript or `LOWER()` in SQL

```typescript
// ✅ Correct - case insensitive
.ilike('referral_code', userEnteredCode)

// ❌ Wrong - case sensitive
.eq('referral_code', userEnteredCode)
```

### Issue: Self-referral attempt
**Cause**: referrer_id = referee_id
**Solution**: Check constraint prevents this at DB level, but add validation in UI

```typescript
if (referrer.id === user.id) {
  throw new Error("You cannot use your own referral code");
}
```

### Issue: Completed status without timestamp
**Cause**: Missing `completed_at` when status is 'completed'
**Solution**: Always set both together

```typescript
// ✅ Correct
status: 'completed',
completed_at: new Date().toISOString()

// ❌ Wrong
status: 'completed',
completed_at: null
```

## 🎯 Performance Tips

1. **Always use case-insensitive lookups**:
   ```sql
   LOWER(referral_code) = LOWER('ABC123')
   ```
   Uses index: `idx_profiles_referral_code_lower`

2. **Filter by status for stats queries**:
   ```sql
   WHERE referrer_id = ? AND status = 'completed'
   ```
   Uses composite index: `idx_referrals_referrer_status`

3. **Check referee uniqueness before insert**:
   ```sql
   SELECT EXISTS (...) FROM referrals WHERE referee_id = ?
   ```
   Uses index: `idx_referrals_referee_id`

## 📊 Monitoring Queries

### Daily referral signups
```sql
SELECT
    DATE(created_at) AS date,
    COUNT(*) AS signups,
    COUNT(*) FILTER (WHERE status = 'completed') AS completed
FROM referrals
WHERE created_at >= NOW() - INTERVAL '7 days'
GROUP BY DATE(created_at)
ORDER BY date DESC;
```

### Conversion rate
```sql
SELECT
    ROUND(
        COUNT(*) FILTER (WHERE status = 'completed') * 100.0 / COUNT(*),
        2
    ) AS conversion_rate_pct
FROM referrals;
```
