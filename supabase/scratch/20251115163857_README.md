## Problem Summary

**Current State:**
- 505 beach_photos in database
- 503 are orphaned (reference non-existent beaches)
- Only 2 are valid (Avila Beach, Carmel River State Beach)
- 74 unique orphaned beach IDs

**Impact:**
- Violates referential integrity
- Featured photos view may break
- Application inconsistency

---

## Solution Overview

This migration will:

1. ✅ **Backup** all orphaned records to audit table (JSONB)
2. ✅ **Delete** 503 orphaned beach_photos
3. ✅ **Verify** FK constraint enforcement
4. ✅ **Preserve** 2 valid photos
5. ✅ **Log** detailed statistics

**After Migration:**
- 2 valid beach_photos remain
- 503 records backed up in `data_cleanup_audit`
- Zero orphaned records
- Referential integrity restored

### 1. Application Code Updates

```typescript

async function insertBeachPhoto(beachId: string, photoData: PhotoData) {
    // Verify beach exists

        .from('beaches')
        .select('id')
        .eq('id', beachId)
        .single();

    if (!beach) {
        throw new Error(`Beach ${beachId} does not exist`);
```
