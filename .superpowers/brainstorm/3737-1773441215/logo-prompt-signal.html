Logo Prompt Design — "The Signal"

Pivoting to the fluid, kinetic direction. One continuous stroke — wave meets data pulse.

Primary Prompt

Gemini Prompt — Copy/Paste Ready
Design a single abstract logo mark for a surf forecast app called "Quiver." The mark should be one continuous fluid stroke — a single bold line that reads as both an ocean swell and an electronic signal pulse. Like a seismograph tracing the ocean's heartbeat, or an oscilloscope rendering a wave's energy. The stroke should feel kinetic and alive, carrying both the chaos of water and the precision of measurement in one gesture. It is not a literal wave and not a literal graph — it lives in the space between both, where you feel the meaning rather than read it. Think of a single confident brushstroke that happens to carry data. Style: Clean flat vector illustration, suitable for use as a logo. One continuous bold stroke or ribbon — consistent weight or with purposeful thick-to-thin variation. No fills, no enclosed shapes, no gradients, no texture, no shading. The mark is the line itself. Color: Deep twilight navy (#252D6B) stroke on a clean white background. Single color only — the mark must work as a silhouette. Composition: Centered on a white background with generous whitespace. The mark should be compact and horizontally oriented — reads clearly at 32 pixels and looks iconic at large scale. No text, no wordmark, no tagline — just the stroke. Do not include: gradients, shadows, 3D effects, realistic textures, literal ocean waves, surfboard shapes, heart monitor lines, wifi symbols, sound wave icons, circular frames, enclosed shapes, or any text.

Variation Prompts

Variation A — Calligraphic Weight
Same prompt as above, but add: Give the stroke expressive thick-to-thin variation, like a brush pen or a calligraphic nib. The weight changes should feel intentional and rhythmic — thickening at peaks, thinning at transitions. One bold gesture with the confidence of Japanese calligraphy.
Variation B — Uniform & Minimal
Same prompt as above, but add: Keep the stroke at a perfectly uniform weight — same thickness throughout, like a wire or a neon tube. Maximum simplicity. The rhythm and movement should come entirely from the path, not from weight variation. Think Paul Rand minimalism meets surf energy.
Variation C — Compact Contained
Same prompt as above, but add: Make the stroke path loop or fold back on itself to create a more compact, square-proportioned mark. The line is still continuous and open (not enclosed), but the path is tighter and more contained — like the signal is coiled with energy. Should fit naturally in a square app icon frame without feeling stretched.

Strategy Notes

  • Horizontal marks are tricky for app icons — that's why Variation C exists. Run it alongside the primary to get a square-friendly version
  • The "do not include" list is critical — Gemini will default to literal waves or wifi symbols without strong exclusions
  • Iterate on the path shape — once you get a stroke you like, ask Gemini: "Keep this exact path shape but [make it bolder / simplify to fewer curves / tighten the spacing]"
  • Test at 32px immediately — fluid strokes can lose readability fast at small sizes. If it muddies, push toward the uniform weight variation
  • Orange accent later — try: "Same mark but the peak of the stroke transitions to charming orange (#F78E42)" for a two-tone version
  • Wordmark pairing — a horizontal signal stroke pairs naturally with type to the right or below. Handle separately.
