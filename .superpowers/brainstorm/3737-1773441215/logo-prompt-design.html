Logo Prompt Design — "The Glyph"

Full prompt crafted for Gemini image generation. Review and approve before we finalize.

Primary Prompt

Gemini Prompt — Copy/Paste Ready
Design a single abstract logo mark for a surf forecast app called "Quiver." The mark should be a bold, geometric, totemic symbol — angular and architectural, but with one fluid curved element that keeps it from feeling rigid. Think of a glyph that could be carved into a surfboard fin or etched onto a circuit board — something that feels both ancient and futuristic simultaneously. The symbol should abstractly evoke the intersection of ocean energy and data precision without being literal — no waves, no surfboards, no screens. It should feel like a mark that carries meaning you sense rather than read. Imagine a Polynesian-inspired modernist icon: sharp faceted edges meeting one organic flowing line. Style: Clean flat vector illustration, suitable for use as a logo. Solid shapes, no gradients, no texture, no shading. Pure geometric construction. The mark should be a single unified shape, not multiple disconnected elements. Color: Deep twilight navy (#252D6B) mark on a clean white background. Single color only — the mark must work as a silhouette. Composition: Centered on a white background with generous whitespace. The mark should be compact and balanced — reads clearly at 32 pixels and looks iconic at large scale. Square aspect ratio. No text, no wordmark, no tagline — just the symbol. Do not include: gradients, shadows, 3D effects, realistic textures, ocean imagery, surfboard shapes, wave illustrations, computer/screen imagery, circular frames, or any text.

Variation Prompts

Run after the primary to explore adjacent directions

Variation A — More Angular
Same prompt as above, but add: Push the geometry further — more faceted, crystalline, sharp. The fluid element should be minimal, just a single curve that breaks the rigidity. Think of a quartz crystal formation or an arrowhead with one softened edge. Maximum boldness and structural presence.
Variation B — More Fluid
Same prompt as above, but add: Let the fluid element take more space — the mark should feel like something caught mid-motion, a frozen gesture. Still geometric in its bones but with more organic curves woven through the angular structure. Think of a calligraphic brushstroke that's been architecturally refined.
Variation C — Signal Hybrid
Same prompt as above, but add: Incorporate a sense of pulse or rhythm into the glyph — as if the geometric structure contains or channels a signal. The mark should feel like it's transmitting something. Think of an antenna or tuning fork that's been abstracted into a totemic symbol. One continuous form that suggests both reception and broadcast.

Prompt Strategy Notes

  • Run primary first — generate 4+ outputs, identify which direction Gemini leans
  • Cherry-pick and iterate — take the best output and ask Gemini to refine: "Keep the overall structure of this mark but make it [more angular / more compact / simpler]"
  • Run variations to explore the spectrum from angular to fluid
  • Test at scale — shrink your favorites to 32x32 in a photo editor. If it turns to mush, it's too detailed
  • Add orange later — once you have a mark you like in navy, try: "Same mark but use charming orange (#F78E42) as an accent on [the fluid element / one facet / the interior shape]"
  • Wordmark separately — don't try to get the logo + text in one generation. Get the mark right, then pair it with type
