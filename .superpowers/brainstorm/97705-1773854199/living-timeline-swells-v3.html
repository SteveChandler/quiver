Every element is data

Wave amplitude

SVG path Y-offset scales with swell height in ft. Primary: tall peaks. Secondary: shallow ripples.

Drift speed

CSS animation duration = swell period. 15s swell = 15s animation cycle. 6s swell = 6s cycle. You see the period.

Drift direction

Animation translateX direction maps to compass bearing relative to beach aspect. SSW at a W-facing beach = slight angle.

Wind particles

Direction: NW = right-to-left (onshore at Blacks). Speed: particle velocity ∝ wind speed. Gusts = occasional fast bursts.

Golden glow intensity

Opacity maps to composite score. 84 = strong glow. 50 = barely visible. 30 = no glow. You see quality before reading numbers.

Scrub behavior

As thumb drags through time: wave heights morph, wind particles change direction/speed, glow shifts. Haptic tick per hour, bump on golden entry.
