## Camera Sourcing Cheat Sheet

### Free Sources (Priority: Exhaust These First)

1. **YouTube Live Streams**
   - Search: "[Beach Name] live cam" or "[Beach Name] surf cam"
   - Explore.org (often has coastal cams)
   - Local news stations (traffic/weather cams)

2. **HDOnTap**
   - Already embedded in app (38 CA cameras from this source)
   - Reliable, stable URLs
   - Contact for partnership/expansion: support@hdontap.com

3. **SurfOutlook**
   - Used for Santa Cruz, Ventura, SF beaches
   - Iframe embed (less ideal but works)
   - May have more coverage than currently mapped

4. **City/Park/Tourism Cams**
   - Coastal city tourism websites
   - State parks (safety/monitoring cams)
   - Lifeguard towers (public safety feeds)

5. **Surfline Partnership**
   - If non-competitive, could license low-res feeds
   - Or embed links with affiliate tracking

### Paid/Partnership Options

1. **Local Surf Shops**
   - Often have existing cams to monitor conditions
   - Quiver branding in exchange for embedding
   - Examples: Ron Jon (Cocoa Beach), ET Surf (Manhattan Beach)

2. **Hotels/Resorts**
   - Beach-facing properties often have lobby/balcony cams
   - Partnership: Free promotion in app for cam access

3. **DIY Installation**
   - For critical gaps with no existing source
   - Cost: ~$1000-2500 per location (camera + cellular + hosting)
   - Solar-powered, 4G-connected, weatherproof PTZ
   - Host at local business (free internet = lower cost)

## Notes for Engineering

All camera URLs should be added via migrations to `beach_sources.camera_url` field.

**Template Migration:**
```sql
BEGIN;

INSERT INTO beach_sources (beach_id, camera_url)
SELECT b.id, urls.camera_url
FROM (VALUES
  ('beach-slug-here', 'https://camera-url-here'),
  ('another-beach', 'https://another-url')
) AS urls(slug, camera_url)
JOIN beaches b ON b.slug = urls.slug
ON CONFLICT (beach_id) DO UPDATE SET camera_url = EXCLUDED.camera_url
WHERE beach_sources.camera_url IS NULL OR beach_sources.camera_url = '';

COMMIT;
```

**Supported Embed Types:**
- HDOnTap: Auto-converts `/stream/` to `/embed/`
- YouTube: Auto-converts `/watch?v=` to `/embed/`
- HLS (.m3u8): Shows "Open camera" fallback link
- Iframe (SurfOutlook): Direct embed

- [ ] Camera loads on desktop Chrome

- [ ] Fallback UI shows for failed loads
- [ ] Performance: Page load time impact <500ms
