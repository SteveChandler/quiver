## Notes For Later Review

- Costa Viva exposes several direct HLS URLs, but many Coastal Camera Network/NJ Beach Cams streams are provider-gated off-site. This migration intentionally uses YouTube watch URLs or provider embed pages for those cases.
- YouTube live IDs can rotate. The selected rows are acceptable for the current "publicly reachable is acceptable for now" posture, but Quiver should validate them periodically.
- The strict SQL overwrite guard means a future non-null camera set between this review and deployment will not be replaced by this migration unless it is already the same URL.
