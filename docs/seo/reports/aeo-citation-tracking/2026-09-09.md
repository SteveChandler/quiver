## Notes

This is a **search-presence proxy**. It measures whether a `quiversurf.app`
result appears in live web search results for each query. It does **not** measure
citations inside Google AI Overviews, ChatGPT, Perplexity, or Gemini, and it is
not an automated Google SERP scrape. No paid backlink index was called.

Method this run: one live search per query via the harness web-search tool, all
30 canonical queries queried verbatim, no added qualifiers and no `site:`
operators, no retries on a query that returned nothing, first page only, host
matching only `quiversurf.app`. The query-set 20/10 split was validated before
the audit. Per-query receipts — verbatim query, returned hosts, matching host and
disposition — are at
`.quiver/reviews/claude-routines/weekly-aeo-citation-audit/20260909T153722Z/search-receipts.md`.

Five citations on a denominator of 30 is a small number. Single-query moves are
within noise at this sample size; read the segment rates as a band, not a point.
