Per `docs/seo/AEO_CITATION_AUDIT.md`, a swing over 20 points with no declared

investigated before publishing. Investigation follows.

### Why 2026-08-17 is the wrong number, not this one

The 2026-08-17 run claimed **20 of 20** informational queries cited. This run
searched all 20 of those same queries verbatim and `quiversurf.app` appeared in
exactly **3**. A 100% informational rate is not reproducible and is not
plausible: for 13 of those queries the first page is entirely surf schools,
Surfline, Surfertoday, and camp blogs, with no Quiver result present at all.

Two likely causes, both worth fixing:

1. **`brandDomains` contains the bare string `"quiver"`.** Matching a host on
   `quiver` rather than `quiversurf.app` will match unrelated domains. This run
   counted only `quiversurf.app` hosts.
2. **Checking existence instead of presence.** Quiver has a `/learn/` page for
   most informational queries. A page existing is not the same as that page
   surfacing in a search, and the audit measures the second.

The 2026-07-27 run (26.7% all, 35.0% informational, 10.0% product/brand) is the
closer comparison. Product/brand at 10.0% is **identical** across that run and
this one, which is the strongest signal that this method is the stable one.

Treat the series as: 2026-07-27 valid, 2026-08-17 **void**, 2026-08-18 valid.

## Competitive note

LazySurfer surfaced on **five** of the ten product/brand queries — best free
surf forecast app, surfline alternative, free surfline alternative, personal
surf forecast app, best app for surf session logging, and best ai surf forecast
app — via purpose-built comparison pages on `lazysurfer.app/compare/*`. Those
pages are the reason it wins queries Quiver is absent from.

This is consistent with the 2026-06-15 backlink report's observation that Quiver
is omitted from LazySurfer's category pages. The gap is not forecast quality; it
is that a competitor has published a page for each of these queries and Quiver
has not.

Note also that the three "beginner surf spots {city}" queries were reported as
surfacing in the 2026-07-27 run and did not surface here. That is a real
regression worth a second look next run before acting on it.

## Notes

This is a **search-presence proxy**. It measures whether a `quiversurf.app`
result appears in live web search results for each query. It does **not**
measure citations inside Google AI Overviews, ChatGPT, Perplexity, or Gemini,
and it is not an automated Google SERP scrape. No paid backlink index was called.

Method this run: one live search per query, query text verbatim, no rewording,
no `site:` operators, no retries, first page only, host must contain
`quiversurf.app`.
