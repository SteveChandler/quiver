## Notes

This is a **search-presence proxy**. It checks whether a `quiversurf.app`
result appears in live web search results for each query. It does **not**
measure citations inside Google AI Overviews, ChatGPT, Perplexity, or Gemini, and
it is not an automated Google SERP scrape. No paid backlink index was called.

Method this run was the same as 2026-09-09:

- One live search per query through the harness web-search tool (US locale).
- All 30 canonical queries, run verbatim with no added qualifiers and no `site:` operators.
- No retries.
- First page only.
- A result counts only when its host matches `quiversurf.app`.

The 20/10 query split was checked before the audit. Per-query receipts are at
`.quiver/reviews/claude-routines/weekly-aeo-citation-audit/20260916T153227Z/search-receipts.md`.
Each receipt records the verbatim query, the returned hosts, the matching host
and the disposition.

App-store results (`apps.apple.com`, `play.google.com`) do not count, even when
they list a surf app, because they are not in `brandDomains`. None of the
app-store listings returned this run was Quiver's.

Four citations out of 30 is a small sample. At this size a single query moving
is noise, so treat the segment rates as a band rather than a point.
