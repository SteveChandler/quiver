### Why 2026-08-31 is voided, not this run

`2026-08-31.md` reported all 33.3%, informational 30.0%, product/brand 40.0%.
Measured against it, today is **−23.3 points** with no method change, which the
runbook classifies as a defect in a run rather than a finding. Four independent
facts place the defect in 2026-08-31.

1. **Its surfaced list is a list of pages that exist, not results that
   appeared.** Every one of the six informational queries it claims has a
   matching published `/learn/` article in `lib/data/learn-articles.ts`:
   `how-accurate-are-surf-forecasts`, `beginner-breaks-san-diego`,
   `beginner-breaks-orange-county`, `best-surf-conditions-for-beginners`,
   `best-tide-for-surfing`, `how-does-water-temperature-affect-surfing`. The
   four product/brand queries map the same way onto `/best-surf-forecast-app`,
   `/personal-surf-forecast`, `/surf-session-log`, and the accuracy page.
2. **It excludes the queries that actually surface.** This is what separates
   enumeration from measurement. `is it safe to surf after rain`,
   `best free surf forecast app`, and `surfline alternative` are the three
   queries that returned a `quiversurf.app` result today, and all three returned
   one on 2026-08-26 as well. 2026-08-31 lists **none of them**. A run that
   measured live results could not have missed the only three that rank while
   catching six that do not.
3. **It is not auditable and was never committed.** The file has no Movement
   section and no action list — two of the runbook's required sections — and
   `git status` shows it as untracked. It is an unreviewed artifact, not part of
   the accepted series.
4. **Its surfaced set is nearly disjoint from both neighbours.** It shares one
   query (`what tide is best for beach breaks`) with 2026-08-26 and **zero**
   with today, while today shares three of five with 2026-08-26. Today
   reproduces the prior valid run; 2026-08-31 reproduces neither side.

This is the same failure as 2026-08-17 and 2026-08-24 — counting page existence
as search presence, in a run that skipped the required sections. It is the third
occurrence in seventeen days.

At 10.0% this run sits just below the reproducible band the series has held

## Analysis: correcting "not ranking"

Three prior runs, and the first draft of this one, concluded that the
informational queries fail because the `/learn/` pages exist and do not rank.
Checked against GSC (`Brand-Vault/seo-audit/2026-08-31/GSC-EXPORT.json`, 28d to
2026-08-28), **that is wrong for most of them.** Eight `/learn/` pages rank on
page one and take almost no clicks:

| Page | Impressions | Clicks | Position |
| --- | ---: | ---: | ---: |
| `/learn/is-it-safe-to-surf-after-rain` | 592 | 2 | 9.7 |
| `/learn/how-are-waves-measured` | 311 | 0 | 7.5 |
| `/learn/best-time-of-day-to-surf` | 97 | 0 | 10.0 |
| `/learn/how-does-water-temperature-affect-surfing` | 40 | 1 | 6.8 |
| `/learn/groundswell-vs-wind-swell` | 30 | 0 | 9.4 |
| `/learn/beginner-breaks-santa-cruz` | 26 | 1 | 8.5 |
| `/learn/how-long-to-learn-to-surf` | 16 | 0 | 9.8 |
| `/learn/how-quiver-calibrates-your-beach` | 6 | 0 | 6.3 |
| **Total** | **1,118** | **4** | — |

**0.36% CTR on page-one positions.** A position-8 result normally takes 2–4%.
The ranking is already won on these; the click is not. That is on-page work and
the opposite of unfixable, and three runs of `[NO ACTION]` were built on a
premise nobody checked against position data.

The citation proxy could not have shown this. It reports presence or absence on
a first page, so "ranks 8th and nobody clicks" and "ranks 41st" both read as
absent. **Do not infer a ranking problem from this instrument.** That rule is now
in the runbook.

Two `/learn` pages *are* genuine ranking failures:
`/learn/how-are-ocean-waves-formed` (625 impressions, position 41.0) and
`/learn/how-to-read-surf-conditions` (34 impressions, position 41.1).

The informational segment lost the two tide queries this run, both served by the
single page `/learn/best-tide-for-surfing`. One page moving off the first page
costs two of twenty queries, which is the whole −10.0 point informational move.
That is a one-page wobble on a denominator of 20, not a trend; it is below the
action threshold and should be re-read next run.

The product/brand first page continues to be held by Surfline, Surf-Forecast.com,
LazySurfer, App Store listings, and roundup blogs. That part stands.

## Notes

This is a **search-presence proxy**. It measures whether a `quiversurf.app`
result appears in live web search results for each query. It does **not** measure
citations inside Google AI Overviews, ChatGPT, Perplexity, or Gemini, and it is
not an automated Google SERP scrape. No full backlink index or paid backlink API
was used.

Method this run: one live search per query, all 30 canonical queries queried
verbatim, no added qualifiers and no `site:` operators, no retries on a query
that returned nothing, first page only, host matching only `quiversurf.app`. The
query-set 20/10 segment split was validated before the audit.

`how do machine learning surf forecasts work` stays in the query set so the
denominator holds at 30, but it is a settled query and no longer generates an
action line. See the settled-queries list in `docs/seo/AEO_CITATION_AUDIT.md`.

Three citations on a denominator of 30 is a small number. Single-query moves are
within noise at this sample size; read the segment rates as a band, not a point.

### 2. Water-temp entity mismatch — 3,607 impressions at 1.58% against a proven 12.78% benchmark

Query-level evidence, stronger than the page-level version in the 2026-08-26
report:

| Group | Queries | Impressions | Clicks | CTR |
| --- | ---: | ---: | ---: | ---: |
| Query names the beach the page names | 11 | 1,072 | 137 | **12.78%** |
| Query names a city, page names a beach | 12 | 3,607 | 57 | **1.58%** |

An **8.1x** gap. Position does not explain it: `santa cruz water temp` sits at

**Audience caveat, stated plainly:** this is the water-temperature swimmer
segment. Plan 064 measured it at 1 signup per 698 sessions (0.14%). It is the
biggest traffic prize on the site and the lowest-value audience Quiver reaches.
That is a business decision, not an SEO one.
