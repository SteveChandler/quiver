# AEO Citation Tracking - 2026-07-07

Status: live search-presence proxy
Scope: 30-query set from `docs/seo/aeo-query-set.json` (20 informational + 10 product/brand)
Method: each query was checked with live web search using a domain-restricted query (`site:quiversurf.app <query>`). "Cited" here means the search engine returned at least one `quiversurf.app` page for that query. This is a **search-presence proxy**, not a true multi-engine AI-answer citation measurement, and not a generic Google SERP rank study.
Engine note: this run used DuckDuckGo HTML search because it was the most stable machine-readable live search surface available in-session.

## Notes

- Only two informational queries returned a `quiversurf.app` result in this proxy check: `best tide for surfing` and `best wind for surfing`.
- No product/brand query surfaced a Quiver page in this proxy run, including `best surf forecast app`, `best free surf forecast app`, `surfline alternative`, `free surfline alternative`, and `best ai surf forecast app`.
- This run does **not** measure answer-engine citations from ChatGPT, Perplexity, Gemini, or Google AI Overviews directly. It only measures whether a live web search engine returned a Quiver page for the query.
- No backlink-index source was used here, and no automated Google SERP scraping was performed.
