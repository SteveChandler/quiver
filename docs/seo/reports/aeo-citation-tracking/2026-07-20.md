# AEO Citation Tracking - 2026-07-20

Status: live search-presence proxy
Scope: 30-query set from `docs/seo/aeo-query-set.json` (20 informational + 10 product/brand)
Method: each query was checked using the available live web-search surface. A query counted as surfaced when that search returned a `quiversurf.app` URL or an explicit Quiver brand mention. The search interface required domain-assisted discovery for part of the set, so this is directional and not directly comparable to an unrestricted Google rank study. This is a **search-presence proxy**, not a true multi-engine AI-answer citation measurement.
