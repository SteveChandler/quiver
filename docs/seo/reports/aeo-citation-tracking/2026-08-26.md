## Notes

This is a **search-presence proxy**. It measures whether a `quiversurf.app`
result appears in live web search results for each query. It does **not** measure
citations inside Google AI Overviews, ChatGPT, Perplexity, or Gemini, and it is
not an automated Google SERP scrape. No full backlink index or paid backlink API
was used.

Method this run: one live search per query, all 30 canonical queries queried
verbatim, no added qualifiers and no `site:` operators, no retries on a query
that returned nothing, first page only, host matching only `quiversurf.app`. The
query-set 20/10 segment split was validated before the audit.

The product/brand segment moved +20.0 points on a denominator of 10, which is a
two-query move. Do not read it as a 20-point trend; one of the two is a genuine
first appearance and the other (`surfline alternative`) is a return of a query
that had surfaced on 2026-08-18 and 2026-08-19.
