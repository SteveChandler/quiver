This run timed the 20 top pages from `VERCEL-EXPORT.json`, one request each under

| `/map` | MISS | 0.24s | 0.22s |

The pattern matches last week's, and this week the mechanism shows. **Every
beach-detail page sampled was a cache MISS.** Beach detail is rendered per request
while the other families are served from cache. It is also the largest family in
the sitemap. GPTBot is not systematically slower than a browser. The AI-crawler
flag looks like the same uncached render, not a penalty for bots.

The headers confirm it: beach reports return `private, no-cache, no-store`. The
cause is not personalization, since the HTML is cookie-free. Commit `c2a3eb13c`
(Sep 7) replaced hourly ISR with per-request rendering on the US, Mexico and
international beach pages, so forecast revisions and time windows match the
moment of the request. Beach `/tides` and `/water-temp` sub-pages are still
cached. Ahrefs' worst spikes (Belmar 8,979 ms, Acapulquito 9,673 ms) were
not reproduced live. Codex measured 157-1,370 ms, and this run measured up to 2.38s.
Every timing is a single sample, and only the first 50 of the 132 slow-page URLs
were collected.
