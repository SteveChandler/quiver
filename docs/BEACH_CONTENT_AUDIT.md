## 📋 **METADATA ANALYSIS**

### **Technical Calibration Data (Already Populated)** ✅

Each beach has the following technical parameters for surf scoring:

1. **Break Type Classification**

   - Beach breaks (60 spots) - Sandy bottom, consistent waves
   - Reef breaks (2 spots) - Rock/coral bottom, powerful waves
   - Point breaks (5 spots) - Wrapping waves, longer rides
   - Jetty/Pier breaks (5 spots) - Man-made structure waves

2. **Hazard Arrays**

   - `rocks` - Rocky areas, reef hazards
   - `rips` - Rip currents (especially jetties/piers)
   - `shorebreak` - Heavy shore break close to beach
   - 22 beaches have documented hazards

3. **Skill Level Ratings**

   - Beginner-Intermediate: 51 beaches (71%)
   - Intermediate: 6 beaches (8%)
   - Intermediate-Advanced: 10 beaches (14%)
   - Advanced: 5 beaches (7%) - Blacks, Windansea, Birdrock

4. **Surf Scoring Parameters** (Technical)
   - **Swell Window**: Optimal wave direction ranges (0-360°)
   - **Tide Preferences**: Min/max tide levels in feet
   - **Wind Thresholds**: Offshore/cross-shore/onshore wind limits
   - **Shoreline Aspect**: Beach orientation for swell exposure

Example for **Ocean Beach**:

```
Break Type: beach
Skill Level: Beginner-Intermediate
Hazards: none
Swell Window: 250° - 390° (SW-NW swells)
Tide Preference: 1.0 - 3.0 ft
Wind Offshore: 140° (SE offshore)
```
