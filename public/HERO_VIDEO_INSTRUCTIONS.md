# Hero Video Setup

## 📁 File Location

Place your surf video at: **`/public/hero-surf-video.mp4`**

```
quiver/
├── public/
│   ├── hero-surf-video.mp4  ← Put your video here
│   ├── placeholder.jpg
│   └── placeholder-user.jpg
```

## 🎥 Video Requirements

- **Format**: MP4 (H.264 codec recommended)
- **Resolution**: 1920x1080 or higher
- **Duration**: 10-30 seconds for optimal loading
- **Size**: Keep under 10MB for fast loading
- **Content**: Beautiful surf footage that loops seamlessly

## 🌊 Recommended Sources

- **Pexels**: https://www.pexels.com/search/videos/surfing/
- **Unsplash**: https://unsplash.com/s/videos/surfing
- **Adobe Stock**: Search "surfing ocean waves"

## 🔄 Fallback

If no video is provided, the page will automatically show the placeholder image instead.

Once you add the video, refresh the page and it will start playing automatically in the background!
