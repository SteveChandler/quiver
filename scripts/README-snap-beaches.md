# Beach Coordinate Snapping Script

## Overview

The `snap-beaches-to-coastline.ts` script verifies beach coordinates using Mapbox reverse geocoding and generates SQL migration files for beaches that need coordinate corrections.

## Purpose

Beach coordinates can become inaccurate over time due to:
- Manual entry errors during initial data import
- Geocoding API changes or improvements
- Database migrations that lost precision
- Coordinate drift in external data sources

This script helps identify and correct these inaccuracies by:
1. Fetching all beach coordinates from Supabase
2. Verifying each coordinate with Mapbox reverse geocoding
3. Calculating the distance between current and suggested coordinates
4. Generating SQL migration files for significant deviations (>50m)

## Usage

### Dry Run (Default)

Shows what changes would be made without writing any files:

```bash
npx tsx scripts/snap-beaches-to-coastline.ts
```

### Generate Migration File

Creates a SQL migration file in `supabase/migrations/`:

```bash
npx tsx scripts/snap-beaches-to-coastline.ts --write
```

### Testing with Limited Beaches

Process only the first N beaches (useful for testing):

```bash
npx tsx scripts/snap-beaches-to-coastline.ts --limit=10
```

### Verbose Output

Show detailed Mapbox API responses:

```bash
npx tsx scripts/snap-beaches-to-coastline.ts --verbose
```

### Combined Flags

```bash
npx tsx scripts/snap-beaches-to-coastline.ts --limit=20 --write --verbose
```

## Environment Variables

Required environment variables (from `.env.local`):

- `NEXT_PUBLIC_SUPABASE_URL` - Supabase project URL
- `SUPABASE_SERVICE_ROLE_KEY` - Service role key for admin access
- `NEXT_PUBLIC_MAPBOX_ACCESS_TOKEN` - Mapbox API token

### Migration File

When run with `--write`, generates a migration file like:

```sql
-- Beach coordinate snap-to-coastline corrections
-- Generated by scripts/snap-beaches-to-coastline.ts on 2026-02-12T...
-- REVIEW CAREFULLY before applying

-- Found 12 beaches with significant coordinate deviations (>50m)

BEGIN;

-- Beach: 38th Avenue (Santa Cruz) (36a2d39e-64f1-4c7e-9618-ac8cc695af62)
--   Location: Santa Cruz, CA
--   Mapbox: 23920 East Cliff Drive, Santa Cruz, California 95062, United States
--   Old: 36.955700, -121.964600
--   New: 36.959327, -121.965698
--   Distance: 415m

UPDATE beaches
SET lat = 36.959327, lon = -121.965698
WHERE id = '36a2d39e-64f1-4c7e-9618-ac8cc695af62';

COMMIT;
```

## Configuration

### Significant Distance Threshold

The script only reports deviations greater than 50 meters. This can be adjusted by modifying `SIGNIFICANT_DISTANCE_M` in the script.

### API Rate Limiting

The script adds a 200ms delay between Mapbox API calls to respect rate limits. This can be adjusted with `API_DELAY_MS`.

## Safety Features

### Coordinate Validation

Uses `lib/coordinate-validation.ts` utilities to validate all coordinates before and after API calls.

### Dry Run by Default

The script defaults to dry-run mode to prevent accidental migration generation.

### Review-Before-Apply

Migration files include detailed comments with:
- Beach name and ID
- Location (city, state)
- Mapbox place name
- Old and new coordinates
- Distance in meters

### Transaction Wrapper

All SQL updates are wrapped in a `BEGIN/COMMIT` transaction for atomicity.

## Best Practices

1. **Always run dry-run first** - Review the output before generating migrations
2. **Test with --limit** - Process a small batch first to verify results
3. **Review migration file** - Manually inspect generated SQL before applying
4. **Test locally first** - Run `supabase db reset` on local dev environment
5. **Backup before applying** - Create a database backup before applying to production

## Troubleshooting

### No beaches found

- Verify `NEXT_PUBLIC_SUPABASE_URL` is correct
- Check `SUPABASE_SERVICE_ROLE_KEY` has read permissions
- Ensure beaches table has records with non-null `lat` and `lon`

### Mapbox API errors

- Verify `NEXT_PUBLIC_MAPBOX_ACCESS_TOKEN` is valid
- Check Mapbox account has available API quota
- Reduce concurrency if hitting rate limits

### Invalid coordinates

The script will skip beaches with invalid coordinates and log warnings. Check console output for details.
