# Design context (pointer)

This file is kept only so that design tools that look for `.impeccable.md` find the current rules.
Do not add design rules here. `soul.md` forbids duplicate guidance.

The current sources are:

- `soul.md`, section "Visual and brand direction": personality, surfaces, type, texture and anti-references.
- `docs/STYLE_GUIDE.md`: tokens, surf-call colors, text tiers and component patterns.
- `app/styles/zine.css` and `components/zine/`: the runtime zine tokens and primitives.
- `docs/BRAND_GUIDE.md`, section "Voice": the copy voice.

The earlier text in this file (navy base, Caveat handwritten accents, 1-3 degree sticker rotations, neon glows, bounce easing) described a retired look. Do not use it.
