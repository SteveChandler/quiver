# Plan 03-04: Validate Landing Visuals Against Brand-Vault

## Goal

Verify that the active landing page uses real Quiver visuals from Brand-Vault or documented derived assets, and that desktop/mobile rendering stays visually sound after the Phase 3 copy and CTA changes.

## Scope

- Inspect active `/` landing image and video references.
- Compare runtime assets against Brand-Vault sources where exact provenance is available.
- Capture desktop and mobile visual evidence for hero, product screenshot, and loop sections.
- Update docs only if the asset source map is stale.

## Non-Goals

- Do not create new graphics or generated media.
- Do not change runtime layout unless validation finds a blocking visual defect.
- Do not add pricing, checkout, App Store status, or RevenueCat claims.

## Verification

- Hash compare app screenshots, nav icon, activity thumbnails, and SSR fallback assets against Brand-Vault.
- Confirm hero media renders locally and document the Brand-Vault source/derivative relationship.
- Use local Playwright/browser capture for desktop and mobile screenshots.
- Run docs/diff sanity checks after edits.
