# Plan 03-05: Landing Validation Gate

## Goal

Close Phase 3 by proving the active landing page copy, iOS CTA wiring, visuals, and crawlable route behavior with focused local checks.

## Scope

- Review existing landing E2E helpers and route coverage.
- Run scoped ESLint for the landing/iOS CTA production and test files touched by Phase 3.
- Run targeted Jest coverage for hero, forecast section, loop showcase, final CTA, App Store banner, and iOS CTA tracking.
- Run TypeScript typecheck with Node 22.
- Run targeted guest landing Playwright coverage on localhost.
- Capture desktop and mobile browser evidence for the landing hero, product screenshot section, and loop section.

## Non-Goals

- Do not broaden into full Playwright suite.
- Do not add pricing/founding offer UI; that starts in Phase 4.
- Do not verify App Store/TestFlight final launch status; that remains Phase 7.

## Verification

- `corepack yarn eslint --max-warnings=0 ...`
- `corepack yarn test:unit ...`
- `corepack yarn typecheck`
- `BASE_URL=http://localhost:3000 corepack yarn playwright test e2e/guest-landing.spec.ts --project=guest --grep "Guest Landing - ML Pipeline Showcase|should display landing page for guests|should have proper page title and meta tags|should have beach links in page HTML for SEO crawlability"`
- Local Playwright visual/browser capture for desktop and mobile.
