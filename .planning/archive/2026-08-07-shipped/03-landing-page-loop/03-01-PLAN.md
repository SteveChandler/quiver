## Objective

Inspect the active landing route architecture, current hero video and CTA tracking, and mobile/desktop behavior so the remaining Phase 3 implementation plans change the right files without weakening auth guards, crawlability, or truth gates.

## Inspection Scope

- Active `/` route composition for anonymous and authenticated users.
- Server-rendered SEO and crawlability surface.
- Hero poster/video loading, CTA placement, and event payloads.
- Active landing sections versus older inactive landing components.
- CTA auth guards and pre-auth event boundaries.
- Known mobile/desktop risks before browser validation.
- Tests that already cover landing behavior and gaps for later plans.

## Non-Goals

- No production landing page code changes.
- No App Store, TestFlight, RevenueCat, Stripe, Vercel env, Supabase, or production data changes.
- No pricing/founding offer UI.
- No public checkout, lifetime, or cross-platform entitlement claims.
- No outbound messaging.
