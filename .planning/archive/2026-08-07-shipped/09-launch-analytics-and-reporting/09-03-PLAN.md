# Plan 09-03: Launch Reporting Path

## Goal

Create a reproducible read-only report path for launch performance.

## Scope

- Document Supabase query groups for launch web analytics.
- Document App Store/TestFlight truth checks.
- Document Brand-Vault tracker sources for email/social state.
- Preserve approval gates for outreach, checkout, entitlement, and production
  mutations.

## Verification

- Runbook says which sources are read-only and which actions remain approval
  gated.
