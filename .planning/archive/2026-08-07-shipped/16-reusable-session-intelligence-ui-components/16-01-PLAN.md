# 16-01: Add Source Badge And Deep-Link CTA

## Objective

Create the small support components that every recommendation card will reuse:
honest source confidence labeling and safe app/universal link CTAs.

## Tasks

1. Add `SourceConfidenceBadge`.
   - Accept `confidence` and `sources` from `SurfWindowRecommendation`.
   - Derive labels such as `High - buoy + model`, `Medium - model + tide`,
     `Low - sparse data`, and `Model only`.
   - Omit unavailable source names.
2. Add `AppDeepLinkCTA`.
   - Prefer `universalLink`.
   - Fall back to `appDeepLink`.
   - Fall back to `IOS_APP_STORE_URL`.
   - Render with `Button` and a real anchor.
3. Add focused component tests.

- Missing optional sources are not displayed.
- CTA hrefs use exact recommendation links when present.
- App Store fallback is safe when links are missing.
