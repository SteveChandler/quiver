# Plan 10-01: Local Launch QA Gate

## Goal

Run the local launch QA gate and collect command evidence for touched launch
surfaces.

## Scope

- Scoped ESLint for launch analytics, blog, page tracker, and landing image
  priority changes.
- Targeted Jest for launch analytics, App Store CTA, pricing, blog, landing, and
  sitemap coverage.
- Node 22 typecheck.
- Preview build with `VERCEL_ENV=preview`.

## Verification

- Commands pass or exact blockers are recorded.
- Build route output includes `/pricing`, `/blog`, and blog post routes.
