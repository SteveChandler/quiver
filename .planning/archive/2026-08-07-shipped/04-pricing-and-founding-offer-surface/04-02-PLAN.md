# Plan 04-02: Waitlist-Safe Pricing UI

## Goal

Build the public pricing/founding-access UI with responsive layout and copy that stays inside the Phase 2 release gate.

## Scope

- Render Founding Access Waitlist as the public offer state.
- Explain beta protection and no automatic charges.
- Teach the forecast -> check -> log -> adjust loop.
- Avoid public prices, checkout claims, monthly/annual/lifetime availability, or native unlock promises.

## Verification

- Unit tests assert the allowed waitlist copy is present.
- Unit tests assert blocked public copy does not render.
- Desktop and mobile screenshots verify the layout has no text overlap or horizontal overflow.
