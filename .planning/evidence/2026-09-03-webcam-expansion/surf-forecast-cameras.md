## Qualifications

- JSON/CSV retain exact embed URLs, thumbnail URLs, provider player URLs, source pages, timestamps and possible duplicates. Channel and individual stream listings can overlap; this is not a count of unique physical cameras.
- Directory proximity is not exact beach coverage. Examples: Mauna Kea hotel is Kaunaoa Bay rather than Hapuna; KONAWEB is Fish Hopper on Alii Drive. Regional discovery can cross state boundaries.
- Commercial embedding permissions, current playback and exact Quiver beach mappings remain unverified. Surf-Forecast framing restrictions do not establish permission to embed third-party providers.
- No application code or production data changed. Inventory structure and counts checked; application/E2E tests not run for research artifacts.
