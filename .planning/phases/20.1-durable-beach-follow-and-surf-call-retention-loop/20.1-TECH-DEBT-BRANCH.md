## Allowed dispositions

Choose exactly one disposition for each commit or logical slice:

- **Reference only:** use its findings and issue map; no code lands.
- **Land audit artifacts:** move durable research, issue mapping, or validation into current planning/docs.
- **Cherry-pick bounded fix:** only for a directly required BFR blocker with isolated tests and no broad refactor coupling.
- **Rebase and open a separate PR:** for coherent tech-debt implementation that should remain independent from Phase 20.1.
- **Superseded:** current `main` or another merged PR already contains the behavior.
- **Retire:** no unique durable value remains after evidence is captured.

Do not merge the entire branch solely because it is named as an audit branch.
