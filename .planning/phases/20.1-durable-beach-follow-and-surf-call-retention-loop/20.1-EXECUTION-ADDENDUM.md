## Global execution changes

### Release truth before implementation truth

Before editing product code, identify for every reused capability:

- where the code lives;
- whether it is on `main`;
- whether it is in `prod` or a distributed native artifact;
- whether a migration is applied;
- whether a flag/config is enabled in the actual bundle;
- whether live/physical evidence exists;
- whether a branch/PR contains unique conflicting work.

`Merged` is not a valid release status.

### Mock state before visual implementation

Before editing a mocked surface, capture or fixture the current shipping state that corresponds to the mock. After implementation, capture the same state and compare:

- hierarchy;
- visible copy semantics;
- state transitions;
- previous/current context;
- accessibility labels;
- responsive/dynamic-type behavior;
- degraded/offline behavior.

The mock is allowed to change only through a written product decision in the plan summary or PR.

### No opportunistic scope absorption

Do not pull these independent workstreams into Phase 20.1 merely because adjacent files are touched:

- native social-share binary PR #131;
- profile-share issue #157;
- App Store PPO issues quiver#399 / quiver-native#92;
- broad map renderer parity or animation issues;
- full lifecycle-email campaign redesign;
- Phase 21 multi-forecaster ingestion;
- generic native performance/debt backlog unrelated to the exact flow being modified.

A direct blocker may be fixed in a bounded slice, but the dependency and reason must be recorded.

# Mock review checkpoint

Before Wave 2 implementation begins, the owner or designated product reviewer must review the six mocks for:

- correct broad-web versus surf-native boundary;
- original utility answer hierarchy;
- topic/intent neutrality;
- exact handoff context;
- native mode continuity;
- watch action simplicity;
- notification restraint;
- outcome/receipt truthfulness.

This review approves the **behavioral direction**, not production polish. Implementation screenshots receive a separate review.
