# 20.1-05: Ship Native Home Continuity, All-User Stability, And One-Tap Watch This Call

<objective>
Turn native Home from a manually reopened live ranking into a trustworthy owned surf-call loop without freezing Now or adding a separate planning state machine.

Purpose: Preserve what question the user asked, prevent small Best revisions from erasing the prior answer, explain real changes, let the user watch the current call in one tap, and return only for decision-relevant updates.

Output: Home mode/recommendation continuity, startup stability, all-user Week Scout rollout, one-tap watched calls, bounded notification categories, analytics, tests, and device evidence.
</objective>
