<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Service-role JSON payload -> PostgreSQL RPC | Caller data can attempt malformed shapes, hash/count tampering, replay, or conflicting slot claims. |
| Private trusted tables -> public roles | Forecaster evidence and internal decision lineage must remain unreadable outside server service-role paths. |
| Local migration -> production ledger | A verified file becomes a production schema mutation only through explicit owner-approved CLI migration tracking. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T21-04 | Information Disclosure / Elevation | Private tables and RPC grants | mitigate | RLS, revoked defaults, service-role-only SELECT/INSERT/EXECUTE, pgTAP privilege probes. |
| T21-05 | Tampering / Repudiation | Build persistence RPC | mitigate | Strict JSON contract, DB canonical SHA-256, advisory lock, exact-count replay checks, receipt-last transaction. |
| T21-06 | Tampering | `ml_predictions_log` | mitigate | `ON CONFLICT DO NOTHING`, immutable applications reference snapshot identity, byte-for-byte pgTAP assertion. |
| T21-07 | Repudiation | Alert acknowledgement | mitigate | Direct mutation blocked; RPC changes only status, actor, timestamp and is service-role-only. |
| T21-08 | Elevation / Tampering | Production schema push | mitigate | Blocking singleton approval; clean detached authorized-SHA worktree; mechanical HEAD/status/project/checksum/pending checks in the push shell; Quiver ledger only; read-only post-push verification. |
| T21-SC | Tampering | Package installation | mitigate | No dependency installation or package-manager task exists in this plan. |
