|----------|-------------|
| Provider HTTPS response -> Seaside parser | Untrusted redirects, markup, JSON, timestamps, units, and ranges enter the service. |
| Seaside normalized issue -> Supabase | Service-role writes must contain validated private issue revisions and sanitized operational status. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T21-01 | Spoofing / Information Disclosure | `trusted_forecasts/fetch.py` | mitigate | Fixed source/host allowlists, HTTPS on every hop, bounded redirects, no credential forwarding, response caps. |
| T21-02 | Tampering / DoS | Source-specific parsers | mitigate | Strict publication/local-window/basis/range validation, authority-ineligible defaults, fixture rejection matrix, bounded parsing input. |
| T21-03 | Spoofing | Provider policy | mitigate | Persist provider lineage/evidence class and dedupe mirrors/models before any later authority vote. |
| T21-09 | Repudiation | Ingest run/source results | mitigate | Append one durable outcome per enabled source and make aggregate health derive from exact outcomes. |
| T21-SC | Tampering | Python dependencies | mitigate | Install no packages; use existing httpx, zoneinfo, APScheduler, and supabase-py only. |
</threat_model>
