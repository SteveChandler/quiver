name: Growth Anti-Patterns (Pre-PMF)
description: Things NOT to do while Quiver has <50 WAU — premature growth tactics that waste effort before product-market fit
type: feedback
---

Do not invest in these until PMF is proven (WASL ≥15, D7 retention ≥15%):

1. **Don't market the referral program** — hide the empty leaderboard. Referral codes with no users to refer create an embarrassing empty state.
2. **Don't add features** — the feature set is built for 100K users and used by 1. Fix activation, don't add complexity.
3. **Don't optimize the landing page** — visitors arrive on beach pages via SEO, not the homepage. The homepage is not the funnel entry point.
4. **Don't launch on Product Hunt** — premature exposure to a broad audience with a broken funnel wastes the one-shot PH launch.
5. **Don't multi-region before San Diego is proven** — win one beach (Blacks/La Jolla) before expanding coverage.
6. **Don't run paid ads** — at 1.6% signup conversion and near-zero retention, paid acquisition has negative ROI.
7. **Don't build more social features** — follows, likes, comments, shares all have zero usage. Fix activation before layering on social.

**Why:** Established during Mar 2026 product discovery. All 4 specialist agents (Growth Hacker, Brand Guardian, Product Manager, Orchestrator) independently converged on these conclusions from actual usage data.

**How to apply:** Before starting any feature work, check if it falls into these categories. If it does, redirect effort toward activation/retention fixes instead.
